# Cynbit Website Redesign

## Project Overview

A UI/UX design assessment focused on improving the navigation, contact experience, and service discoverability of the Cynbit website.

The redesign explores targeted improvements while maintaining the website's professional technology focused visual identity.

## Key UX Improvements

1. Improved navigation with a dedicated Home link and a clickable logo.
2. Active navigation states to help users identify their current page.
3. A more prominent inquiry form with a Project Type dropdown.
4. Four structured service cards with concise descriptions and clear calls to action.
5. A dedicated Services navigation link to demonstrate easier access to service information.
